# Murata-High-Voltage-Capacitor-Cross-Reference

**Murata DHS / DHR High Voltage Capacitor Cross-Reference**

Murata's screw-terminal (DHS) and radial-lead (DHR) high voltage ceramic capacitor series are discontinued. This guide lists the discontinued Murata part numbers and the drop-in HVC replacements, with voltage, capacitance and dielectric data.

📖 **Full guide with the complete cross-reference table: https://hvc-capacitor.github.io/murata-dhs-dhr-cross-reference/**

## Series covered

- DHR series — radial lead, 10–15 kV
- DHS series — screw terminal, 20–40 kV
- All replacements use the same N4700 low-loss dielectric class and industry-standard mounting dimensions
